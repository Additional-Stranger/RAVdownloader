One-line: 20px status label for job state, codec, and channel metadata.

```jsx
<Badge tone="processing" icon="loader">Encoding</Badge>
<Badge tone="ok" variant="solid">Complete</Badge>
<Badge tone="live" variant="outline">On air</Badge>
<Badge uppercase={false}>ProRes 422 HQ</Badge>
```

`soft` is the default in tables. Reserve `solid` for a single emphatic state per row.
