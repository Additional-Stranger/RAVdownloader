# Changelog

## 1.0.0 (2026-09-01)

First public release of Edit Bay Studio.

- Eight tools: Downloader, Social Media, Convert, Extractor, Merge, Podcast, VO Maker, Lower Third.
- Sign-in with an Edit Bay Tools account; plans and trials managed at editbaytools.com.
- Windows x64 installer and macOS (Apple silicon) disk image.
- In-app updater for the app and its bundled tools.
- Bug reports can be sent from inside the app.
